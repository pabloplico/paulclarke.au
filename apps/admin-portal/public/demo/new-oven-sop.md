# New deck oven: operating procedure

Harbourside Bakery is a fictional business. This file is sample data for a software demo.

The new three-deck oven arrives on the 3rd and replaces deck oven 2.

## Starting the oven

1. Turn the main isolator on at the wall.
2. Set each deck to 230 °C. The display shows the deck temperature, not the set point; wait until all three read 230.
3. Heating takes about 50 minutes from cold, ten minutes longer than the old oven. The first baker should switch it on at 4:30 am as before.

## Steam

Each deck has its own steam button. Press it for three seconds after loading sourdough. Don't hold it longer: the new oven injects more water than the old one.

## Shutting down

Set every deck to off, leave the doors ajar for 30 minutes to let the steam out, then close them. Never turn off the isolator while the decks are above 100 °C; the fans need to keep running.

## Faults

If a deck shows E4, it's the door switch: close the door firmly and press reset. For any other code, call Tropic Oven Services. The oven is under warranty for two years, so don't let anyone else work on it.
